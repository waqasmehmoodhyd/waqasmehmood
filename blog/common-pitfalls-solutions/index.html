Common Pitfalls & Solutions for Detailed SEO & AI Engine

Below are the most frequent “yellow‑line” warnings Chrome shows after the extension is installed, plus step‑by‑step resolutions.

1. “Proceed with caution” safe‑browsing notice

Reason: Chrome’s Enhanced Safe Browsing flags any newly‑published extension. Fix: Add a verified badge on the landing page and keep the extension’s privacy‑policy link updated (already done in `ext/index.html`).

2. Title‑length warning ( > 60 chars )

Reason: The extension’s auto‑suggested title exceeds the SERP limit. Fix: The extension now truncates titles automatically and shows a live counter.

3. Missing or duplicate meta description

Reason: Pages generated from the extension sometimes inherit the site‑wide description. Fix: Use the “Edit description” button in the UI; the new value is saved locally and exported in the PDF report.

4. 404 soft‑error on unknown routes

Reason: The sub‑domain lacked an `ErrorDocument`. Fix: Added an `.htaccess` rule (`ErrorDocument 404 /404.html`) and a custom 404 page (already live).

5. Schema‑validation failures

Reason: JSON‑LD snippets were outdated. Solution: The extension’s built‑in validator now pulls the latest schema versions from schema.org automatically.

All issues have been addressed in the latest version (v 2.3.1). If you encounter anything else, open a support ticket via the extension’s “Help” panel.
